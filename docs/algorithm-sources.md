# 基础盘算法与参考资料

[中文首页](../README.md) · [扩展规则](extensions.md) · [测试指南](validation.md)

本项目的默认计算口径为：**时家、拆补、转盘，中五固定寄坤，天禽随天芮**。它是可复现的算法约定，不代表所有奇门流派只有一种排法。飞盘、置闰、茅山及其他寄宫方法不属于当前默认算法。可选注记使用独立的配置和结果字段。

现已实现的暗干、旺衰、十二长生、刑墓、日马与门迫，均通过参数显式启用，详细公式及原典依据见 [扩展规则](extensions.md)。这些注解不改变本文定义的基础盘。

## 时间与计算边界

输入首先明确时区偏移、日界和时间口径，再计算四柱。年柱按立春交节瞬间切换，月柱按十二节的交节瞬间切换；奇门定局使用全部二十四节气。不能用固定公历日期代替交节时刻，不能将农历初一当作月柱边界。

拆补使用**排盘时刻正在生效的节气**，不是符头发生日期的节气。节气切换时即使仍在同一时辰，局数也可能改变。日界选择影响日柱、时柱和三元，必须保留在输入及输出约定中。

## 三元与局数

令日柱的六十甲子索引 `d` 为 `0..59`，甲子为 0：

- 符头索引：`5 * floor(d / 5)`，即最近一个甲日或己日。
- 三元索引：`floor(d / 5) % 3`，依次为上、中、下元。
- 等价检查：符头地支子午卯酉为上元，寅申巳亥为中元，辰戌丑未为下元。

- 飞宫数字顺序：`1,2,3,4,5,6,7,8,9`。
- 转盘顺时针外环：`1,8,3,4,9,2,7,6`。

### 地盘与旬首

以局数为戊的起宫，按数字九宫阳顺阴逆布 `戊己庚辛壬癸丁丙乙`。因此阳一局的地盘 1 至 9 宫为同一字符串。地盘中五宫的干始终保留。

### 值符、九星与天盘干

1. 找出时旬所遁仪在地盘的**原宫** `p`，保留 `p = 5` 的可能。
2. 原宫的九星为值符星。若 `p = 5`，值符星是天禽，不应改名为天芮。
3. 找出时干地盘宫 `t`；时干为甲时以本旬所遁仪代甲。定义 `host(5) = 2`，其他宫不变。
4. 将外环从 `host(p)` 整体旋转到 `host(t)`。星序固定，阴遁也不反转星的相对顺序。
5. 各星携带其本宫地盘干形成天盘干。天禽与天芮同宫，天禽另外携带地盘中五干；该附加干在每一盘都存在，不能只在值符为禽时补上。

九星在逻辑上只有九颗。中宫的静态本位、保留的地盘干、随芮落宫的天禽应明确分层，避免消费者将重复展示误认为两颗天禽。九个天盘干应可完整找回，包括作为附加字段的寄干。

### 值使与八门

值使门取原宫 `p` 的门；`p = 5` 借坤二死门。令阳遁 `s = 1`，阴遁 `s = -1`：

`raw = rem_euclid(p - 1 + s * (h % 10), 9) + 1`

值使落宫为 `host(raw)`。**先以原宫飞九宫，完成后再寄宫**；先将起点 5 改成 2 会造成错误。八门以值使为锚点沿固定外环整体旋转，阴遁也不改变门序。

### 八神、空亡与马星

八神从值符实际落宫起，按 `值符、腾蛇、太阴、六合、白虎、玄武、九地、九天` 排布，阳遁顺时针，阴遁逆时针。此处不采用阳遁换勾陈、朱雀的异名方案。

空亡先保留地支，再映射宫位并去重。例如甲子旬的戌亥均属乾六宫，不能输出两个不同的空宫。时家盘标示时旬空；日空及其他柱的旬空应有不同字段。

| --- | --- | ---: |
| 申、子、辰 | 寅 | 8 |
| 寅、午、戌 | 申 | 2 |
| 亥、卯、未 | 巳 | 4 |
| 巳、酉、丑 | 亥 | 6 |

## 参考案例

基础盘测试包含阴遁与阳遁的外部参考案例，以及按本页公式推导的中宫、寄干和环序案例。各案例的输入、来源、字段转录和名称映射保存在[测试资料](../crates/qimen-core/tests/fixtures/README.md)。

## 已识别的参考实现差异

- `kinqimen/config.py` 的 `yin_eightgua_order` 为 `艮乾兑坤离巽震坎`，并非本项目外环的严格逆序；代码中阳遁还使用勾陈、朱雀。默认规则不能直接照搬。
- `3meta/src/qimen/calculator.ts` 中，值符目标中宫寄坤，值使目标中宫却阳寄艮、阴寄坤；值使计步起点也先将旬首中宫改成坤宫。这与本项目固定寄坤、原宫起步约定不同。
- `qimen-go` 的数据展示保留中宫天禽和中宫干；比较时必须规范化寄宫字段，不能用输出字符串位置代替逻辑九星归属。
- `taobi` 部分步骤仍带 TODO 或未核验标记，部分测试仅测单旬、且有 `circle.pop()`；不能把上游测试通过等同于覆盖全部十八局、六十时柱与时间边界。

长期回归应分别覆盖历法、二十四节气边界、十八局乘六十时柱的纯排盘组合、寄宫不变量及外部整盘案例。若外部数据与当前规则冲突，先保留双方输入和差异，再判断是流派差异还是实现错误，不以更新快照消除失败。
