# 奇门天盘 · Web

[项目首页](../../README.md) · [计算约定](../../docs/algorithm-sources.md) · [扩展注记](../../docs/extensions.md)

面向桌面与手机的奇门排盘应用。以星垣深空、古金罗盘与宋体中文呈现九宫，输入公历时间即可查看八字、局数和完整盘面；排盘在浏览器中计算，无需登录。

## 开始使用

需要 Node.js 22 或更高版本。在仓库目录执行：

```bash
cd apps/web
npm ci
npm run dev
```

打开 [localhost:3000](http://localhost:3000)。如需运行优化后的正式构建：

```bash
npm run build
npm start
```

应用通过 npm 的 `@spensercai/qimen-wasm` 包计算，安装和构建时无需 Rust 工具链。

## 起局与读盘

1. 选择**公历日期**与**当地时间**，填写当天适用的 UTC 偏移。北京时间为 `+08:00`；「此刻」按当前选择的偏移填写时间。
2. 选择换日规则：**子初 · 23时**或**午夜 · 0时**。按需开启扩展注记。
3. 点击**开始排盘**。罗盘短暂旋转后呈现结果，顶部显示四柱、阴阳遁、局数、值符与值使。
4. 点击九宫中的任一宫位，在详情区查看盘层、寄干、星门神、空亡、马星和注记。

盘面采用传统方位：上南下北、左东右西，中宫位于正中。前后时辰按钮每次移动两个小时，并保留时区和计算规则。示例入口可直接填入一组完整时间。

输入为民用时间，不自动换算真太阳时。四柱由日期和时间计算；单独给出八个干支字不能唯一确定公历时刻。支持公元 1–9999 年的前推格里高利历，远古、远期的天文精度与历史颁历差异见[时间范围说明](../../docs/usage.md#历史日期与远期日期)。

## 扩展与显示

| 注记     | 显示内容                               |
| -------- | -------------------------------------- |
| 暗干     | 按值使门时干法及中宫回退规则排列的暗干 |
| 旺衰     | 九星、八门、宫位及月令的关系           |
| 十二长生 | 各盘层天干在宫位地支中的长生阶段       |
| 六仪击刑 | 六仪的击刑标记                         |
| 入墓     | 可选古典三奇入墓或十二长生墓           |
| 日马     | 日支三合局驿马，与基础盘时马分别显示   |
| 门迫     | 门五行克宫五行的标记                   |

修改选项后再次排盘生效。注记只补充基础盘，不改变局数或九宫排列；各项所用流派规则见[扩展规则](../../docs/extensions.md)。

页面遵循系统的减弱动态效果偏好，也可使用页面中的动效开关。键盘可操作输入、选项和宫位。桌面三栏随窗口高度自适应，常见电脑窗口可一屏查看输入、完整盘面和操作；较长的宫位详情在栏内滚动。较矮窗口保留页面滚动，窄屏下各区块顺序排布。

中文采用随应用提供的思源宋体，输入与操作区域使用深色实底，减少星云背景对阅读的干扰。天仪弧线与背景星图仅为装饰，不参与排盘计算；真实星门神与方位以九宫及详情区为准。

## 分享与导出

分享链接记录日期、时间、时区、换日规则与扩展选项，接收者打开后重新计算同一组输入。链接包含排盘时间，发送前请确认这些信息适合公开。

JSON 导出保留库的结构化结果，适合保存或与其他接入方式交换；「复制结果」将同一份 JSON 放入剪贴板。分享与导出以当前已完成的盘面为准。

## 数据与隐私

排盘引擎在浏览器的 Web Worker 中执行，输入不会发送到排盘服务器。浏览器仅保存时区、换日、扩展和动效偏好，不自动保存日期或盘面历史；清除网站数据即可重置偏好。禁用本地存储不会影响排盘。

初次打开需要下载页面与 WASM 资源。应用不承诺在未加载资源或浏览器清理缓存后离线启动。
